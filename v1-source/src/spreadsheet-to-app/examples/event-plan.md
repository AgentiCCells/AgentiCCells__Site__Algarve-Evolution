# Spreadsheet to App Day: a mock event plan (simulated)

A one-day session run by Algarve Evolution. The format follows the Vibathon Algarve 2026.

## To take part
- An account with a model that can build an app: Lovable, Claude, ChatGPT, Mistral or similar. Free tiers can work; event credits help.
- A spreadsheet or document from your work, **with dummy data** that looks like the real thing and can be published. Or use one of the five examples.
- A laptop and a charger.

## The day
| Time | What |
|---|---|
| 09:00 | Welcome; why spreadsheets become apps now (15 min) |
| 09:15 | Demo: one example spreadsheet to a published app, live, with the five prompts (30 min) |
| 09:45 | Build, part 1: prompts 1 and 2, with mentors at the tables |
| 11:30 | Show one thing that worked and one that broke (two minutes per table) |
| 12:00 | Lunch |
| 13:00 | Build, part 2: prompts 3, 4 and 5; publish |
| 15:30 | Share: give your app to someone at another table and watch them use it |
| 16:00 | The handover: what it takes for five or fifty people to use it (backups, changes, security) |
| 16:45 | Show and tell; the jury's picks |
| 17:30 | Next steps: who will release which apps properly, and how |

## Where the apps live
- Option A: each participant publishes from their own tool (Lovable, a Claude artifact, a ChatGPT canvas).
- Option B: Algarve Evolution has a GitHub organisation for the day, with a template repository; each participant gets a repository from the template, and the app is published with GitHub Pages.
- Option C: a small team of providers takes the apps published in A and moves them into B for the participants, during the afternoon.

## After the day
- Every app has a page with its owner's permission.
- A follow-up within a week: what the app needs to be used by others, and who in the region can do it.
