# The five examples, the prompts and the mock event plan

These files are copied unchanged from the public, read-only sgit vault `ph10xfc1`, "Spreadsheet to App: examples, prompts and a mock event (simulated)", version v1.1.0 (31 October 2026, built on commit 47dac00f13ac), published by the SGit Newsroom with the article "Spreadsheet to App: a session programme for Algarve Evolution" (https://newsroom.sgit.ai/articles/spreadsheet-to-app-sessions.html, by Dinis Cruz, 31 October 2026).

- `01-holiday-home-changeover.md`: closing the house, a holiday home checklist (a document, the important steps in bold)
- `02-restaurant-stock.csv`: a restaurant's stock and suppliers
- `03-surf-school-bookings.csv`: a surf school's bookings
- `04-freelancer-invoices.csv`: a freelancer's invoices
- `05-association-members-events.csv`: an association's members and events
- `prompts.md`: the five prompts, in order
- `event-plan.md`: the mock one-day event (simulated)

Everything in them is invented. Licence: CC BY 4.0 (the vault's own licence), credit the SGit Newsroom.

The working tool at /spreadsheet-to-app/ reads these files in the browser. The converted holiday home app at /spreadsheet-to-app/example/ is the vault's `app/index.html`, with one change: the prototype banner and design picker that every page of this site carries were added after `<body>`, and their stylesheet and script were linked. Nothing else was changed.
