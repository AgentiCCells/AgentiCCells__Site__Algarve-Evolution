# The talent map's vault

The data in `data/` also lives in the sgit vault `eii0x48f`, created on 16 November 2026 by sites@AgentiCCells.dinis, as Dinis Cruz asked ("create a vault for it and put the data in there and then consume it"). `scripts/sync-talent-vault.sh` pulls it into `data/` with a key passed in `TALENT_VAULT_KEY`. No key is stored in this repository; whether the read-only key is published, as the site vault's is, is Dinis's decision.
