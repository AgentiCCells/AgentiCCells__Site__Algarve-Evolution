# Five prompts, in order

Use any model that can build and publish a small web app: Lovable, Claude, ChatGPT, Mistral or another. Paste your spreadsheet (dummy data only) or one of the examples with the first prompt, then send the others one at a time, using the app between each.

## 1. A list I can search
> Here is my spreadsheet, with dummy data. Build a single-page web app that shows it as a list I can search and filter. Keep the data in the browser: no database, no login, no server. Show the columns that matter most first.

## 2. Add and change rows
> Add a form to add a row and to edit or delete one. Save everything in the browser's local storage, and add buttons to export the data as CSV and to import it again.

## 3. The view I use most
> The view I use most is: [today's tasks / what to order / unpaid invoices / this week's lessons / members who have not paid]. Make it the first screen, with the most important items first, and let me mark each one done.

## 4. Remember every run
> Every time I finish a run (a day, an order, a session), keep a small dated record of what I did, what I skipped and a note. Show the history as a list, newest first.

## 5. Publish it and say what it is
> Publish it so someone else can open it. Write a short "about" section: what the app does, where the data is kept, and what it does not do yet.

After the five: use it for real, then come back with what broke or what you missed. That is the next prompt.
